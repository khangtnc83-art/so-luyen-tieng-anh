# Sổ Luyện Tiếng Anh

Trang web ôn ngữ pháp, từ vựng và luyện nói tiếng Anh giao tiếp — học Thứ 2 và Thứ 5 hằng tuần.

- Trang web: thư mục `docs/` (GitHub Pages phục vụ từ đây)
- Nội dung bài học: `docs/data/content.js`
- Từ vựng 3000 từ: `docs/data/vocab3000.js` (câu ví dụ từ Tatoeba — CC BY 2.0 FR; gia đình từ & đồng nghĩa từ WordNet)
- Kho dữ liệu chung (Google Sheet): `google-sheet-script.gs` — dán vào Apps Script của Google Sheet
- Chế độ giáo viên: mở trang với `#giaovien` ở cuối link
